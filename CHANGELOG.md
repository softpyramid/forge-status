# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-19

### Added
- Initial release of Laravel Forge Webhook Status package
- Real-time deployment status indicator via webhooks
- Support for Laravel 10, 11, and 12
- WebSocket updates via Laravel Echo
- Tailwind CSS styling with configurable positioning
- Auto-injection into Laravel layouts
- Optional webhook token security
- Comprehensive test suite
- GitHub Actions CI/CD pipeline
- Complete documentation with troubleshooting guide

### Features
- 🚀 Real-time WebSocket updates
- 🎯 No database storage (cache only)
- 🔗 Webhook-driven architecture
- 🎨 Auto-injection into layouts
- ⚙️ Configurable position and authentication
- 🎭 Modern UI with Tailwind CSS
- 📱 Responsive design

### Requirements
- PHP 8.2+ (Laravel 12 compatibility)
- Laravel 10, 11, or 12
- Laravel Broadcasting configured
- Laravel Echo on frontend
